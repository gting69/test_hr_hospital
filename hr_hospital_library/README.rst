Hr Hospital Library
===================

Цей модуль призначений для автоматизації роботи невеликої лікарні.
Він є частиною навчального проекту.

Основні функції:
----------------
* Облік лікарів (з урахуванням спеціалізацій та менторства).
* Керування картками пацієнтів.
* Реєстрація візитів до лікарів та встановлення діагнозів.
* Класифікатор хвороб.
* Майстер для масового перепризначення лікарів.
* Звіти та друковані форми.

Встановлення:
-------------
1. Скопіюйте модуль у папку аддонів.
2. Оновіть список додатків.
3. Встановіть модуль `hr_hospital_library`.
