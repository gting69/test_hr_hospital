Hr Hospital Library

Система автоматизації медичного закладу

Цей модуль розроблений для керування базовими процесами лікарні. Він дозволяє вести облік лікарів, пацієнтів, історію візитів та діагнозів.

Основні можливості:

  • Керування картками пацієнтів та лікарів
  • Планування візитів
  • Класифікатор хвороб з перекладом
  • Звіти по навантаженню лікарів
